# SFace model notice

This directory contains `face_recognition_sface_2021dec_int8bq.onnx` from
OpenCV Zoo, `opencv/opencv_zoo`, under the model directory's Apache 2.0 notice.

Model: SFace / MobileFaceNet, block-quantized int8, 128-dimensional feature
output.

Source:
https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface

The application uses the model only for local feature extraction. The
employee templates remain branch-scoped and encrypted on the Android device.
Preserve this notice and the Apache 2.0 license when redistributing the APK.
